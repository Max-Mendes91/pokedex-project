# Pokedex Web App

A fully functional **Pokedex web application** built with **React**, **Vite**, and **Tailwind CSS**.  
Explore, search, and view details of Pokémon with a sleek, dark-themed UI.

---

## Features

- **Browse Pokémon**: View a list of Pokémon with pagination for easy navigation.
- **Search Pokémon**: Quickly find Pokémon by name.
- **Pokémon Details**: Click any Pokémon to see detailed information including types, stats, and images.
- **Minimalist Header**: A simple, centered "POKEDEX" title with gold accents.
- **Dark Theme & Gold Accents**: High-contrast UI with visually appealing styling.
- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **Performance Optimized**: Fast loading and smooth interactions.
- **Accessibility Friendly**: Readable text, proper contrast, and focus states.

---

## Technologies Used

- **React** – for building dynamic user interfaces
- **Vite** – fast development server and build tool
- **Tailwind CSS** – utility-first styling for rapid UI development
- **React Router** – seamless client-side routing
- **PokeAPI** – fetches Pokémon data in real time
